# Performance v2: первый эксперимент с нижней границей PnL

Дата: 2026-10-01. Исследование на предоставленных пользователем Excel;
новые правила в панель и базу не внедрялись.

## Вход и правило

Шесть пар, все LONG, 1 903 строки исходного Finalists. По последнему решению
группа — **пара + сторона**, все ТФ пары объединяются. Предыдущий вариант
с 37 группами «пара + сторона + ТФ» оставлен как историческое сравнение.
Пользователь разрешил текущий отбор панели как основу.
Исходные 5 001 строка All candidates также сохранены в книге.
Новые согласованные пять фильтров отдельно не воспроизводились.

В каждой группе для метрики берём верхние ceil(N/2) доступных значений
и их медиану. Пробная граница — доля этой медианы.
Основной порядок, уточнённый пользователем: **sequential** — сначала B/30,
затем полный PnL/30 на оставшихся после B. Исключённые по B не участвуют
во втором ориентире и получают отметку «ПРОПУЩЕН ПОСЛЕ B».
Альтернативный **parallel** считает обе границы по исходной группе.
Значение строго ниже применимой границы исключает.
Равенство проходит. Недоступный показатель не становится нулём и не отменяет
известное нарушение другого условия. При неполной оценке без нарушения
стратегия остаётся с N/A. Неположительная медиана не задаёт adaptive-границу.

Доли 60/70/80% — настройки эксперимента, не доля сохраняемых стратегий и
не согласованные пороги будущего фильтра. Основной файл создан с 70% / 70%.

Расчёт использует именно эти значения; точность до округления не восстанавливается.

этапе учитывает только доходности, и коэффициенты ещё предстоит выбрать.

## Работа с книгой

Последний запрос: две простые книги с отбором по паре целиком:

- `Output/FilterExp/FilterExp_PnL_pairs_60_70_80.xlsx` — sequential.
- `Output/FilterExp/FilterExp_PnL_pairs_parallel_60_70_80.xlsx` — parallel.

В каждой **только три листа 60%, 70%, 80%**; на каждом все 1903 исходных
Finalists. Коэффициент листа применяется к обеим метрикам. В sequential
full-группа — оставшиеся после B; в parallel обе группы исходные.

В начале каждого листа три сигнала для стандартного фильтра Excel:
«Прошла B/30», «Прошла PnL/30», «Итог». ДА — прошла, НЕТ — исключена,
N/A — оценка неизвестна; «—» у полного PnL означает пропуск после B failures.
Для просмотра отсечённых выбрать НЕТ в «Итог», для прошедших ДА;
если нужно сохранить неизвестные без известного нарушения, также выбрать N/A.
Далее идут исходные стандартные колонки с метриками, без удаления строк.
Никаких настроек или запуска обработчика для просмотра этой книги не нужно.

Предыдущие книги 001–003 и простая книга по ТФ — исторические прототипы.
Использовать их как основной интерфейс пользователь отказался.

Локальный `pnl_rules.py` содержит только расчёт на обычных Python-записях;
`run_pnl_experiment.py` читает и записывает Excel. Будущая панель сможет применять
согласованный расчёт напрямую к фактам базы, затем выгружать готовый результат.
Ранжирование и структурные сравнения в этот эксперимент не включены.
Простую трёхлистовую книгу создаёт `build_three_pnl_sheets.py` с тем же
расчётным ядром; существующий результат защищён от перезаписи.
