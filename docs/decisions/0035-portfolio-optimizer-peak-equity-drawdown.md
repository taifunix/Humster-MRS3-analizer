# ADR-0035: MaxDD нового поиска относительно пика equity

**Дата:** 2026-09-13

**Статус:** Accepted пользователем для нового алгоритма поиска; реализация
и независимое review полного алгоритма не выполнены.

## Контекст

В [черновике нового поиска](../superpowers/plans/2026-09-12-portfolio-optimizer-weighted-search-discussion.md)
обсуждалась нормировка денежной просадки на стартовый банк. Пользователь сначала
согласовал только значения 20 / 10 / 5%, явно оставив знаменатель открытым,
затем отдельно подтвердил расчёт «от пика equity».

## Решение

- MaxDD — максимальная относительная просадка общей equity от предшествующего
  пика: `H_t=max(E_s, 0<=s<=t)`, `MaxDD_peak=max_t((H_t-E_t)/H_t)`, `E_0=B>0`.
- Лимиты AGGRESSIVE / BALANCED / CONSERVATIVE: 20 / 10 / 5% соответственно.
- Пиковая база сохраняется до нового HH за рассматриваемый период.
  Промежуточные локальные вершины ниже прежнего максимума её не сбрасывают;
  новый HH не удаляет уже наблюдавшийся MaxDD периода.
- Equity учитывает открытый ПНЛ и расходы согласно исходному контракту.
  Стартовый банк, wallet balance или текущая equity внизу просадки не являются
  знаменателем этого показателя.
- Максимум ищется по относительным просадкам всех моментов. Эпизод наибольшего
  денежного DD не обязательно является эпизодом наибольшего процентного DD.
- Денежный MaxDD и его отношение к стартовому банку допустимы как отдельная
  аналитика; дополнительного обязательного ограничения из них не создаём.

## Последствия и границы

Для предварительной модели `E_t=B+g_t(x)` с постоянными размерами позиций x и
фиксированным лимитом m ограничение записывается линейно: `E_t>=(1-m)H_t`,
`H_0=B`, `H_t>=H_(t-1)`, `H_t>=E_t`. После решения фактический MaxDD вычисляется
из общей equity. Для фиксированных x требование по этому ограничению составляет
`max(0, max_t((h_t-g_t)/m-h_t))`, где `h_t=max(g_s, 0<=s<=t)`, при отдельном
условии `B>0`. Это только компонент необходимого банка, без маржи и CDaR.

Bootstrap-проверка, если будет принята, должна использовать пиковый знаменатель
каждого сценария при проверяемом банке. Прежняя формула «денежный MaxDD / m»
не является расчётом капитала для согласованной относительной просадки.

Решение не утверждает методику/нормировку CDaR, параметры bootstrap, резерв,
маржинальные пороги, автоматические действия на live-счёте или весь алгоритм.
Для будущего live-анализа внешние денежные потоки должны быть отделены от
торгового результата; формулы выше относятся к тесту без пополнений/выводов.

Этот ADR заменяет только предложение стартового знаменателя в новом черновике.
Он сохраняет смысл peak-to-trough процента из [ADR-0029](0029-portfolio-optimizer-research-risk-profile-v1.md)
и не переписывает старую политику, её evidence или runtime задним числом.
