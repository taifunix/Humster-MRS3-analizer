# Historical sources

Files in this tree preserve provenance only. They are not the active v0.7 contract.

- `v0.6/` contains the migrated implementation baseline, original algorithm specifications, handoffs and historical implementation notes.
- `sources/` contains the long-form v0.7 master handoff, the future portfolio-selector source specification, and other imported source material used as evidence for focused active specifications.

Use these files only through links from an active specification, PRD entry or ADR. When an archived rule conflicts with an approved active specification, the active specification wins.
