# Шаблоны стратегий тестера

Это единственный отслеживаемый каталог исходных JSON-шаблонов, из которых
панель формирует стратегии для бота/тестера.

- `source-v6-mrs2/long.json` и `source-v6-mrs2/short.json` — MRS2-шаблоны
  первичного тестирования, отчёты которого импортируются в Source v6.
- Шаблоны MRS3 (READY, RETEST) и оптимизатора зависят от биржи и лежат в
  [`../exchanges/`](../exchanges/README.md).

`Input/` не является источником шаблонов: каталог локальный и игнорируется Git.
Изменение шаблона требует проверки генерации обеих сторон и отдельного review.
